# MetaCerta
MetaCerta é uma plataforma de planejamento financeiro pessoal que permite cadastrar metas mensais ao longo do ano, acompanhar o progresso das economias e desbloquear recompensas ao atingir os objetivos. Organize suas finanças, acompanhe suas conquistas e transforme suas metas em experiências, como passeios, viagens, restaurantes e muito mais.
